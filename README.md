# Herdr Git Graph

A [Herdr](https://herdr.dev) mod that draws a GitKraken-style commit graph (lanes, branch/merge curves, refs) for the repo of the focused terminal or space.

Uncommitted changes show as a dotted `// WIP` row on top (✎ modified, + added, − deleted), and each stash as a dotted box above the commit it was made on; right-click a stash to apply, pop or delete it. Clicking the WIP row lists the changed files with their line counts; click a file for its diff. Commits and stashes list their files the same way.

Pull (the current branch) and Stash (everything uncommitted, untracked files too) sit above the graph.

Click a commit for its details; right-click it to check out its branch (local, or a remote one as a new tracking branch) or the commit itself, detached.

## Install

```sh
git clone git@github.com:PatKeb/herdr-git-graph.git ~/.config/herdr-app/mods/git-graph
```

Herdr hot-reloads mods. Put it in a layout as a block, e.g. in a side panel stack:

```json
{ "id": "graph", "type": "block", "content": { "mod": "git-graph" } }
```

`gpui-kit.d.ts` (typings) is generated by Herdr and not tracked.
